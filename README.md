# العلوم — الصف الأول الابتدائي (الكتاب التفاعلي)

كتاب تفاعلي مطابق لكتاب «العلوم» للصف الأول الابتدائي (كتاب التلميذ ٢٠٠ صفحة + كتاب النشاط ٧٦ صفحة)، مصمَّم للشاشات التفاعلية والأطفال:

- **كتاب التلميذ:** الصفحات الأصلية نفسها، على كل سؤال زر 💡 يُظهر الإجابة، ومراجعات الفصول تفاعلية (أصل بخط، ✓ و ✗، أضع دائرة) مع زر «تحقّق».
- **كتاب النشاط:** كل نشاط يُحلّ على الصفحة نفسها بالإصبع: أصل بخط، أضع علامة، أضع دائرة، أرقّم، أختار الكلمة، أصنّف في جدول، والتلوين بالألوان على الرسوم، مع «تحقّق» و«الحل».
- **٣٤ لعبة تعليمية** من صور الكتاب: تصنيف، ترتيب مراحل النمو، توصيل، الطفو والغطس، المخلوط، المصباح والصندوق المظلم، الدفع والسحب…
- قلم وممحاة وتلوين على أي صفحة، تكبير وتصغير، وفهرس صفحات مصغّرة.

- **الموقع:** https://zraij.github.io/sci1/ (يحتاج تسجيل دخول)
- **إدارة الحسابات:** https://zraij.github.io/sci1/admin.html
- **رابط التثبيت (للأساتذة والشاشات):** https://zraij.github.io/sci1/install.html

محتوى البرنامج وصور الكتابين مشفّرة ولا تُفتح إلا بحساب صحيح، مع قفل الجهاز (نفس خدمة الكيمياء والفيزياء والأحياء) وحقوق المصمم.
