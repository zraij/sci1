# العلوم — الصف الأول الابتدائي (الكتاب التفاعلي)

كتاب تفاعلي مطابق لكتاب «العلوم» للصف الأول الابتدائي (كتاب التلميذ ٢٠٠ صفحة + كتاب النشاط ٧٦ صفحة)، مصمَّم للشاشات التفاعلية والأطفال:

- **كتاب التلميذ:** الصفحات الأصلية نفسها، على كل سؤال زر 💡 يُظهر الإجابة، ومراجعات الفصول تفاعلية (أصل بخط، ✓ و ✗، أضع دائرة) مع زر «تحقّق».
- **كتاب النشاط:** كل نشاط يُحلّ على الصفحة نفسها بالإصبع: أصل بخط، أضع علامة، أضع دائرة، أرقّم، أختار الكلمة، أصنّف في جدول، والتلوين بالألوان على الرسوم، مع «تحقّق» و«الحل».
- **٣٤ لعبة تعليمية** من صور الكتاب: تصنيف، ترتيب مراحل النمو، توصيل، الطفو والغطس، المخلوط، المصباح والصندوق المظلم، الدفع والسحب…
- قلم وممحاة وتلوين على أي صفحة، تكبير وتصغير، وفهرس صفحات مصغّرة.
- **🎬 الشرح المتحرك:** ٢٥ درساً (٢٤ درساً + «أكون عالماً») بشرائح تُعرض خطوة بخطوة: رسوم متحركة، دورات حياة، أجزاء النبات والحيوان والإنسان، الحواس، الكرة الأرضية، الفصول الأربعة، البركان…، وأسئلة مصوّرة بعد كل فكرة.
- **🧪 ١٣ مختبراً افتراضياً:** هل هو كائن حي؟ نبتتان في الضوء والظلام، أزرع بذرة، الشيء المخبّأ (الحواس)، العدسة والتربة، صفات المواد، أثر الحرارة، الدائرة الكهربائية، اهتزاز الوتر، خفيف وثقيل، الماء أم اليابسة، المياه الجارية، ملابس الفصول.
- **🗺️ خريطة المغامرة** بالنجوم والملصقات، **🃏 بطاقات المفردات**، **📝 اختبار لكل فصل**، **🏆 تحدّي الفرق**، و**🧰 أدوات الأستاذ** (مؤقّت، اختيار تلميذ عشوائي، نجوم الصف).

- **الموقع:** https://zraij.github.io/sci1/ (يحتاج تسجيل دخول)
- **إدارة الحسابات:** https://zraij.github.io/sci1/admin.html
- **لوحة إدارة موحّدة:** نفس `admin.html` موجود بكل الكتب ويدير كل الكتب من مكان واحد (أزرار للتبديل بين الكتب). أي تعديل عليه لازم ينسخ لكل المستودعات.
- **الاشتراكات:** كل حساب (عدا المدير) له تاريخ انتهاء `e` بـ `users.json` (`pm` = عدد الأشهر، `tr` = أيام التجربة). الحسابات القديمة بدون تاريخ تنتهي `2026-12-01` (من 1 تشرين الثاني لمدة شهر). عند الانتهاء تظهر شاشة التجديد برقم 07746451098.
- **تنبيه للمطوّر:** كود الاشتراك (`subFetch` / `subExpired` / `subBadge`) مضاف بالجزء غير المشفّر من `index.html`؛ بعد أي إعادة بناء تأكد أنه موجود.
- **رابط التثبيت (للأساتذة والشاشات):** https://zraij.github.io/sci1/install.html

محتوى البرنامج وصور الكتابين مشفّرة ولا تُفتح إلا بحساب صحيح، مع قفل الجهاز (نفس خدمة الكيمياء والفيزياء والأحياء) وحقوق المصمم.
